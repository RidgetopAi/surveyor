# Surveyor

Codebase mapping and visualization tool.

## Setup

```bash
# Install dependencies
pnpm install

# Run UI in development
pnpm dev

# Build all packages
pnpm build
```

## Packages

- `@surveyor/core` - Parser and analysis engine
- `@surveyor/ui` - React visualization app
